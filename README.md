# 20 Hazır Claude Skill - Türkçe

Türkiye'deki beyaz yakalı profesyoneller için hazırlanmış 20 Claude skill paketi.

## İndirme

[ZIP olarak indir](https://github.com/bahadir-digital/claude-skills-tr/releases/latest)

## Kullanım

Detaylı kullanım rehberi ve blog yazısı:
https://bahadir.digital/turkiyenin-beyaz-yakalisina-20-hazir-claude-skill/

### Kurulum

1. ZIP dosyasını indir ve aç
2. Claude.ai'da **Settings → Capabilities → Skills** bölümüne gir
3. Her klasörü Claude'a yükle (drag & drop)
4. İlgili senaryo karşına geldiğinde skill otomatik tetiklenir
